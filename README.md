# Shubham's Diwali Dhamaka 🪔

A single-file responsive invitation site for **Saturday, 31 October 2026 at 6:30 PM**, hosted by Shubham in Andheri East, Mumbai.

## Host for free with GitHub Pages

1. Create a **public** repository under `amanhosts` called `diwali-dhamaka`.
2. Upload `index.html` to the **root** of that repository and commit it.
3. In the repo, select **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Pick `main` and `/ (root)`; click **Save**.
5. Your website address will be `https://amanhosts.github.io/diwali-dhamaka/` after deployment.

## Custom-named URL

- Free custom-looking URL: change the repository name to your desired slug, such as `shubham-ki-diwali`, giving `https://amanhosts.github.io/shubham-ki-diwali/`.
- Fully custom domain, e.g. `shubhamkidiwali.in`: buy the domain; configure the GitHub Pages **Custom domain** setting and the DNS records according to GitHub's instructions. Domain registration usually costs money.

## RSVP behavior

The form collects a name, attendance, a drink preference (Wine/Vodka/Whiskey/Gin/Rum plus non-alcoholic choices), and Veg or Non-veg. Submitting opens a **pre-filled WhatsApp message**, which the guest must **send to Shubham or the party group**. The site does **not** automatically store RSVPs or know Shubham's phone number. To collect RSVP submissions into a spreadsheet, add a form backend such as Google Forms, Formspree, or Netlify Forms. Do not claim the WhatsApp step is automatic collection.

## Customization

Everything is in `index.html`. Search for the date, address, or shayari to edit. No build tools required; simply open `index.html` locally in a browser to preview.
